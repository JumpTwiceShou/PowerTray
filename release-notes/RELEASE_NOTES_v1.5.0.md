## What's New

- Added selectable tray hover display modes: disabled, Windows native, or PowerTray custom. Custom hover follows live light/dark theme changes; Windows native or disabled mode avoids the known rare Windows 11 top-left issue. Mode changes take effect after restart.
- Improved Logitech detection and recovery with faster direct-USB and LIGHTSPEED receiver reconnects, more reliable hotplug handling, quicker Centurion headset power-off detection, and broader read-only device support.
- Replaced low-battery exclamation marks with blinking red battery indicators, added scrolling for larger tray device lists, and expanded and corrected English, Simplified Chinese, and Japanese interface text.
- Hardened atomic settings saves, battery polling, restart handoff, crash logging, and privacy; the local device API is now always restricted to loopback.
